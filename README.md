# Random Advice Web App

Fun web app that gives you a piece of random advice after sharing
how you feel. This a node.js web app.<br>

Feel free to try it out! In order to try it out do the following: 
* Clone this repository
* Make sure you're in the main directory for this web app after cloning 
* Install the necessary dependencies needed to run the app
  * run **npm i** to install
* In your terminal run **nodemon index.js**
* To visit the web app
  * Open your favorite web browser
  * In the web address bar type **localhost:3000**
  * Enjoy the app
